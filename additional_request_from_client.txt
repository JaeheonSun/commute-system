제가 매월 직원들의 시간외근무를 파악해서 급여를 계산해야 하는데요. 직원들이 날짜별 출퇴근 시간과 시간외근무 시간을 정확히 기록할 수 있도록 프로그램에 약간의 기능 보완을 부탁드리고자 합니다.
개발 시 구조를 잡으실 때 도움이 되도록 재단의 근무 형태와 필요한 입력 항목을 정리해 보았습니다.

[출퇴근 프로그램 보완 요청 사항]
1. 핵심 필요 기능
직원별 날짜별 출근/퇴근 시간 기록 기능
직원별 날짜별 시간외근무 시간 산출 및 기록 기능
2. 근무 형태별 세부 요구 조건 (총 7가지)
프로그램상에서 직원이 '근무 형태'를 선택할 때, 항목별로 아래의 내용이 입력될 수 있도록 구현을 부탁드립니다.
① 재택근무: 자택 근무 (기본형)
필요 항목: 출근 시간, 퇴근 시간 입력
② 재단근무: 사무실 출근 (기본형)
필요 항목: 출근 시간, 퇴근 시간 입력
③ 시차 (유연근무): 출퇴근 시간을 조정하여 근무하는 형태
필요 항목: 해당 일자의 출근 시간(시작)과 퇴근 시간(종료)을 명확히 지정하여 입력하는 란
④ 연차: 1일(종일) 휴가
시간 입력 불필요 (해당일은 근무 시간 0 처리)
⑤ 반차: 4시간 근무 + 4시간 휴가 (예: 9시~18시 근무자 기준)
필요 항목: 당일 중 실제 근무한 시간대(4시간)를 입력할 수 있는 란
⑥ 특별휴가: 이사장님 특별 부여 휴가
시간 입력 불필요 (종일 휴가와 동일하게 처리)
⑦ 대체휴무: 주말(토, 일) 특근 발생 시 평일에 쉬는 보상 휴무
필요 항목: 비고란 입력 필수 활성화
비고란 용도: 직원이 '어떤 날짜'에 '무슨 업무'로 주말 근무를 해서 사용하는 대체휴무인지 사유 기재
